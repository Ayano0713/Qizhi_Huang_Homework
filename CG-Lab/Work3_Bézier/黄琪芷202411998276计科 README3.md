基于 Python + Taichi GPU 实现交互式贝塞尔曲线绘制实验，完成 De Casteljau 算法实现、GPU 批量光栅化像素渲染、鼠标 / 键盘交互功能，直观展示贝塞尔曲线几何原理与图形 CPU/GPU 批量渲染优化思想。
环境依赖
Python 3.8+
taichi
numpy
安装命令：
bash
运行
pip install taichi numpy

运行方式
bash
运行
python bezier_curve.py

操作交互说明
添加控制点：鼠标左键点击画布，生成红色圆点控制点，最多支持 100 个控制点；
生成贝塞尔曲线：控制点≥2 个时自动实时渲染绿色贝塞尔曲线，灰色线段为控制点多边形；
清空画布：按下键盘 c 键，清除所有控制点与曲线。
核心实现要点
De Casteljau 算法：CPU 递归线性插值计算任意 t 下曲线上浮点坐标；
GPU 批量光栅化：CPU 一次性计算全部采样点，批量传入 GPU 显存，由 Taichi Kernel 并行点亮像素，规避频繁 CPU-GPU 数据传输卡顿；
固定显存池优化：预先分配定长 GPU Field 存储控制点与线段索引，不动态申请显存；
坐标映射：[0,1] 归一化鼠标坐标转换为 800×800 屏幕像素索引，带越界检测防止数组溢出。
实验对应学习目标
理解贝塞尔曲线几何定义与 De Casteljau 递归插值原理；
掌握 GPU 批量渲染、像素缓冲区光栅化基础流程；
熟悉 Taichi GGUI 鼠标 / 键盘交互、CPU-GPU 数据批传输优化方案。
