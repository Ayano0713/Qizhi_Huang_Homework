# 可微软光栅化三维网格重建实验 README

## 项目简介

基于 PyTorch + PyTorch3D 实现**软可微光栅化网格逆向重建**实验：以细分球体作为初始网格，通过多视角奶牛剪影图像做监督，使用梯度下降迭代形变球体顶点，逐步拟合出奶牛三维模型；引入拉普拉斯平滑、边长惩罚、法线一致性三类正则项避免网格拓扑崩坏，完整验证软光栅化解决梯度消失、正则化约束网格几何形态的核心理论。

## 实验流程说明

1. **目标模型预处理**
   加载 `cow.obj` 奶牛网格，归一化顶点至单位空间；生成20个环绕均匀视角，通过**软剪影光栅器**渲染多视角灰度轮廓图作为监督真值。
2. **初始化待优化网格**
   创建4级细分二十面体球体作为初始源网格，`deform_verts` 顶点偏移量设为可微优化参数。
3. **可微渲染前向传播**
   用当前偏移量形变球体网格，复用同一套摄像机与光栅管线渲染预测剪影。
4. **复合损失计算（核心）**
   $$L_{total} = L_{silhouette} + w_{lap}L_{lap} + w_{edge}L_{edge}L_{normal}$$
   - $L_{silhouette}$：预测剪影与真值剪影MSE误差，驱动网格贴合目标轮廓
   - $L_{lap}$ 拉普拉斯平滑损失：抑制表面尖锐凸起
   - $L_{edge}$ 边长损失：约束三角面边长均匀，防止拉伸压缩
   - $L_{normal}$ 法线一致性损失：保证相邻面片朝向接近，维持光滑曲面
5. **梯度反向传播优化**
   SGD优化器更新顶点偏移，迭代300轮逐步把球体捏成奶牛形状。
6. **可视化与输出**
   每20轮保存当前网格为`.obj`，绘制「真值剪影/当前预测剪影」对比图，直观观察形变收敛过程。

## 关键技术原理对应代码实现

### 1. 软光栅化解决梯度消失

传统硬光栅像素内外阶跃无梯度；SoftSilhouetteShader 使用Sigmoid做边缘平滑过渡，`blur_radius`、`sigma` 控制模糊程度，像素边界存在连续梯度，允许顶点沿轮廓方向优化。

```python
raster_settings=RasterizationSettings(image_size=256, blur_radius=np.log(1./1e-4 - 1.)*1e-4, faces_per_pixel=50)
shader = SoftSilhouetteShader(blend_params=BlendParams(sigma=1e-4, gamma=1e-4))
```

### 2. 多视角监督

20个环绕旋转相机，批量渲染多视角剪影，单视角易陷入局部最优，多视角约束保证三维几何正确。

```python
num_views = 20
R, T = look_at_view_transform(2.7, torch.zeros(num_views), torch.linspace(-180, 180, num_views))
cameras = FoVPerspectiveCameras(R=R, T=T, device=device)
```

### 3. 三类网格正则化（防拓扑崩坏）

```python
loss = loss_silhouette + \
       1.0 * mesh_laplacian_smoothing(new_src_mesh) + \
       0.1 * mesh_edge_loss(new_src_mesh) + \
       0.01 * mesh_normal_consistency(new_src_mesh)
```

- 无正则：顶点自由漂移、三角面重叠穿插，网格变成毛刺“刺猬”；
- 正则共同约束：平衡轮廓拟合与网格几何光滑性。

## 常见问题

1. FileNotFoundError: cow.obj
   解决：将奶牛obj模型放到代码同一文件夹；
2. CUDA out of memory
   解决：减小`image_size`（如128）或降低`num_views`；无GPU会自动切换CPU运行（速度很慢）；
3. 网格出现严重毛刺、无法收敛
   解决：调大拉普拉斯、边长正则权重，增加迭代轮次。
