# 质点-弹簧布料模拟（三种数值积分对比）README

## 项目简介

基于Taichi GPU并行实现布料质点弹簧物理模拟，完整实现**显式欧拉、半隐式欧拉、定点迭代隐式欧拉**三种数值积分求解器，可实时切换对比稳定性差异；通过胡克定律计算弹簧弹力、阻尼力、重力，增加速度钳制解决数值爆炸；搭配GGUI交互面板支持模拟暂停、布料重置、相机自由漫游，直观展示不同积分算法的稳定特性与GPU并行物理仿真架构。

## 环境依赖

- Python 3.8+
- taichi（支持GPU CUDA/Metal）
  安装命令：
  
  ```bash
  pip install taichi
  ```

## 运行指令

```bash
python cloth_mass_spring.py
```

## 场景与物理参数说明

1. **布料网格**：20×20质点网格，左上角、右上角质点固定悬挂，自由下落摆动形成布料效果
2. **力学参数**
   - 质点质量：1.0
   - 弹簧劲度系数：10000.0
   - 阻尼系数：1.0
   - 重力：(0, -9.8, 0)
   - 速度上限：50.0（防爆钳制）
   - 单时间步长 dt = 5e-4，每帧迭代40次子步保证实时稳定
3. **摄像机**：初始位置(0,0.5,2.0)，右键按住可拖拽旋转视角、WSAD移动
4. **渲染内容**：蓝色质点圆点 + 白色弹簧线框

## GGUI交互面板功能

窗口左上角控制面板，功能如下：

1. 积分算法切换按钮（切换时自动重置布料）
   - [*] Explicit Euler：显式欧拉，极易数值爆炸、剧烈抖动
   - [*] Semi-Implicit Euler：半隐式欧拉，平衡稳定，实验推荐
   - [*] Implicit Euler：隐式欧拉（定点迭代近似），阻尼强、几乎不发散
2. Pause/Resume Simulation：暂停/恢复物理模拟
3. Reset Cloth：重置布料至初始悬挂状态

## 核心实现模块与原理

### 1. 模块化GPU初始化（保证同步）

拆分为3个独立Kernel分步初始化，Python层顺序调用，规避多线程显存同步冲突：

- init_positions：初始化质点位置、速度、固定约束标记
- init_springs：遍历网格生成横向、纵向结构弹簧，原子计数统计弹簧总数
- init_spring_indices：同步弹簧连线索引，用于3D线框渲染

### 2. 力计算与防爆函数（ti.func内联优化）

- compute_forces_on：统一计算重力、阻尼力、弹簧弹力；弹簧力使用`ti.atomic_add`解决多线程写入竞争
- clamp_velocity：速度模长超限后归一压缩，抑制显式欧拉高频发散爆炸
- 均封装为`@ti.func`，编译期内联进积分Kernel，消除GPU函数调用开销

### 3. 三种积分求解Kernel（单Kernel合并力计算+更新，最小化启动开销）

1. **显式欧拉 Explicit Euler**
   先用当前受力更新速度，再用旧速度更新位置，稳定性最差，大步长直接崩解；
2. **半隐式欧拉 Semi-Implicit Euler**
   先更新速度，再用新速度更新位置（辛欧拉），能量震荡可控，工程最常用；
3. **隐式欧拉 Implicit Euler（定点迭代近似）**
   迭代预测下一时刻位置、速度与受力，使用未来状态更新，强阻尼、稳定性最强，布料运动偏僵硬。

### 4. GPU并行架构优化要点

1. 受力计算、积分更新全部整合在单个Kernel，每物理子步仅一次GPU调度；
2. 弹簧多线程累加力使用原子操作atomic_add避免数据竞争；
3. 循环迭代使用`ti.static`编译期展开，消除运行时循环开销；
4. 所有质点、弹簧数据预分配定长Field，无运行时动态显存申请。

## 实验现象对比

1. 显式欧拉：布料下落剧烈抖动，短时间内直接数值爆炸、网格飞散；
2. 半隐式欧拉：布料自然摆动，轻微弹性震荡，无崩坏，视觉效果最佳；
3. 隐式欧拉：布料运动柔和、阻尼感强，几乎无弹跳，不会出现发散，但弹性表现力弱。

## 常见问题

1. 布料切换显式欧拉立刻飞散：属于算法固有不稳定特性，是预期实验现象；
2. 画面卡顿：无GPU环境下CPU运行速度大幅下降，建议开启CUDA/Metal；
3. 布料固定点脱落：网格初始化逻辑约束角落质点，重置布料即可恢复。
