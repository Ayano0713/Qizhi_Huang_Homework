# Phong光照模型光线投射渲染实验

## 项目简介

基于 Python + Taichi GPU 实现光线投射（Ray Casting）离线软渲染，完整实现经典 Phong 局部光照模型，包含球体、圆锥隐式几何体求交、Z-buffer 深度遮挡、三通道光照着色与实时 UI 参数调节，直观展示环境光/漫反射/镜面高光对物体渲染效果的影响。

## 环境依赖

- Python 3.8+
- taichi
  安装命令：
  
  ```bash
  pip install taichi
  ```

## 运行程序

```bash
python phong_raycast.py
```

## 界面交互说明

窗口右侧弹出材质参数控制面板，拖动滑块实时修改渲染效果，参数范围与默认值：

1. Ka（环境光系数）：0.0 ~ 1.0，默认 0.2
2. Kd（漫反射系数）：0.0 ~ 1.0，默认 0.7
3. Ks（镜面高光系数）：0.0 ~ 1.0，默认 0.5
4. N（高光指数Shininess）：1.0 ~ 128.0，默认 32.0

## 场景内容

1. **摄像机**：固定在世界坐标 (0, 0, 5)
2. **点光源**：位置 (2, 3, 4)，白光 (1,1,1)
3. **红色球体**：左侧，中心(-1.2, -0.2, 0)，半径1.2，固有色(0.8,0.1,0.1)
4. **紫色圆锥**：右侧，顶点(1.2,1.2,0)，底面y=-1.4，底面半径1.2，固有色(0.6,0.2,0.8)
5. **背景**：深青色 (0.05, 0.15, 0.15)

## 核心实现功能

1. **隐式几何体光线求交**
   - 球体解析几何光线相交，自动计算交点表面法向量
   - 竖直圆锥解析求交，限定高度区间过滤无效交点
2. **深度测试(Z-buffer)**
   遍历所有几何体求交结果，保留最小正交点距离，实现物体正确遮挡关系
3. **Phong 着色器**
   - 环境光 Ambient：模拟全局均匀背景光照
   - 漫反射 Diffuse：基于Lambert余弦定律，与光线、法向量夹角正相关
   - 镜面高光 Specular：计算反射向量与视线夹角，高光指数控制光斑大小
     三通道颜色叠加并裁剪至0~1合法像素区间
4. **GPU并行渲染**
   Taichi kernel 并行遍历屏幕所有像素发射光线，渲染性能高效
5. **实时GUI交互**
   内置滑动条绑定光照材质参数，修改后下一帧即时刷新渲染画面

## 对应实验学习目标

1. 掌握Phong光照模型三大光照分量数学公式与视觉表现差异

3. 理解光线投射渲染管线：像素射线生成、几何体求交、深度遮挡、逐像素着色完整流程
4. 学会Taichi GPU并行渲染与GUI交互控件开发，可视化调节渲染材质参数
