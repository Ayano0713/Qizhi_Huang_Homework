# Whitted-Style 光线追踪实验 README

## 项目简介

基于 Python + Taichi GPU 实现迭代式经典 Whitted 光线追踪，区分光线投射与光线追踪；实现硬阴影、镜面反射、棋盘格地板纹理，采用迭代循环替代递归适配GPU并行，提供GUI实时调节光源坐标与光线最大弹射次数，直观展示全局反射光照效果。

## 环境依赖

- Python 3.8+
- taichi
  安装命令：
  
  ```bash
  pip install taichi
  ```

## 运行指令

```bash
python ray_tracing_whitted.py
```

## 场景几何体与材质说明

场景全部使用隐式几何体定义，内置材质ID区分反射/漫反射物体：

1. **地面无限平面（漫反射）**
   高度 y=-1.0，法线朝上；黑白棋盘格纹理，通过交点X/Z坐标奇偶生成；
2. **左侧红色漫反射球体**
   中心(-1.2, 0, 0)，半径1.0，仅产生漫反射与阴影，无反射；
3. **右侧银色镜面球体**
   中心(1.2, 0, 0)，半径1.0，理想镜面材质，可反射场景物体、阴影与地面棋盘格。

摄像机：起点 `(0, 1, 5)`，视角轻微向下；背景深青蓝色。

## 交互面板参数说明

窗口右侧控制面板，拖动滑块实时重绘画面：

1. Light X / Light Y / Light Z：点光源三维坐标，范围 X/Z [-5,5]、Y [1,8]，拖动可移动阴影位置；
2. Max Bounces：光线最大弹射次数，范围1~5，默认3
   - 弹射=1：仅主光线，无镜面反射效果；
   - 弹射>1：镜面球体产生多层反射，呈现镜中世界。

## 核心实现功能

1. **迭代式光线追踪（GPU友好）**
   摒弃递归，使用for循环迭代追踪反射光线；维护`throughput`光线吞吐量记录光线能量衰减，镜面每次反射乘以0.8反射率衰减能量，漫反射直接终止光线传播。
2. **硬阴影（Shadow Ray）**
   物体交点向光源发射暗影射线，若中途与几何体相交则当前点处于阴影，仅保留环境光。
3. **自相交Bug修复（Shadow Acne）**
   反射射线、阴影射线起点沿法线偏移极小偏移量`1e-4`，避免射线与自身表面重相交产生黑色噪点。
4. **几何体光线求交**
   实现球体、水平无限平面解析求交，统一场景遍历函数返回最近交点、法线、物体颜色、材质类型。
5. **棋盘格程序化纹理**
   地面平面通过交点世界坐标计算网格奇偶，自动生成黑白相间地板纹理。
6. **GPU并行渲染**
   Taichi kernel并行遍历全部像素发射主光线，完整光线追踪流程在GPU并行执行，渲染高效。

## 对应实验学习目标

1. 区分光线投射（仅单次主光线、无次级射线）与光线追踪（支持阴影射线、反射次级射线）核心差异；
2. 掌握Whitted风格全局光照实现思路：阴影测试、理想镜面反射、光线能量衰减；
3. 理解GPU并行限制，掌握将递归光线追踪改写为迭代循环的工程方案；
4. 掌握阴影痤疮(Shadow Acne)成因与法线偏移标准解决方案；
5. 学会程序化纹理生成、交互式光源参数调节，直观理解弹射次数对反射效果的影响。
